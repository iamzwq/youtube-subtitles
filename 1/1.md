# YouTube 中文字幕与中文配音

自动完成：下载视频和词级字幕、选择单一字幕轨道、LLM 翻译、生成中文字幕、
Edge TTS 中文配音，以及字幕烧录和视频合成。

## 安装

先进入脚本目录，并创建 Python 虚拟环境。

Windows：

```bat
cd D:\workspace\
python -m venv .venv
.venv\Scripts\activate
pip install yt-dlp openai edge-tts numpy
winget install Gyan.FFmpeg
```

macOS：

```bash
cd /path/to/
python3 -m venv .venv
source .venv/bin/activate
pip install yt-dlp openai edge-tts numpy
brew install ffmpeg
```

## 配置

首次运行会在脚本目录生成 `config.json`，填写 LLM API Key。默认配置包括：

```json
{
  "llm": {
    "provider": "mimo",
    "base_url": "https://token-plan-cn.xiaomimimo.com/v1",
    "api_key": "你的 API Key",
    "model": "mimo-v2.5-pro",
    "supports_system_role": false,
    "thinking": { "type": "disabled" },
    "batch_size": 40,
    "batch_max_chars": 8000
  },
  "tts": {
    "enabled": true,
    "engine": "edge-tts",
    "voice": "zh-CN-YunyangNeural",
    "rate": "+0%",
    "volume": "+0%",
    "pitch": "+0Hz",
    "mix_with_original": false,
    "batch_size": 50,
    "concurrency": 5,
    "max_tempo": 3.0,
    // "engine": "mimo",
    // "model": "mimo-v2.5-tts-voiceclone",
    // "base_url": "https://api.xiaomimimo.com/v1",
    // "api_key": "你的 TTS 用 Key",
    "clone_ref_start_s": 0,
    "clone_ref_duration_s": 20
  },
  "subtitle": {
    "max_chars_per_line": 35
  }
}
```

`thinking.type` 默认是 `disabled`，用于关闭 MiMo LLM 的思考模式。使用其他
OpenAI 兼容服务时，修改 `base_url`、`api_key` 和 `model`。

## 运行

```bat
python 1.py "https://www.youtube.com/watch?v=视频ID"
```

参数：

| 参数               | 作用                                       |
| ------------------ | ------------------------------------------ |
| `-o, --output DIR` | 指定输出根目录，默认 `./youtube_downloads` |
| `--no-video`       | 只生成字幕，不下载视频、不配音、不烧录     |
| `--no-tts`         | 下载视频并烧录字幕，但跳过中文配音         |
| `--no-nvenc`       | 禁用 NVIDIA GPU 硬件编码，强制使用 CPU     |

## 字幕与翻译

- 优先选择视频语言对应的自动字幕，只下载一条字幕轨道。
- 自动字幕不可用时，再回退到人工字幕，不会同时下载两类字幕。
- `[Music]`、`[Applause]`、`(upbeat music)` 和音符符号会被移除；只含这些内容的
  字幕会被丢弃。
- LLM 每批最多翻译 40 句、8,000 个原文字符，并按批保存翻译缓存。
- 翻译缓存会在字幕内容或模型变化时失效；重新运行会从未完成位置继续。
- 当前英文分句主要依赖原字幕标点；没有标点的自动字幕可能形成较长句子。

## TTS 缓存

- TTS 每批最多生成 50 条，最多同时请求 5 条。
- `tts_cache.json` 会校验字幕文本和 TTS 配置，避免复用错误音频。
- 中途失败时保留已经生成的音频，重新运行时跳过有效缓存。
- 最终视频成功生成后，才删除 TTS 音频、混合音频和 TTS 缓存清单。
- FFmpeg 或 TTS 失败时，缓存会保留；成功后缓存会被清理，这是正常行为。

## 输出目录

产物位于 `输出目录/视频ID/`：

```text
视频ID.mp4                 原始视频
视频ID.jpg                 视频封面
视频ID.<语言>.json3        原语言词级字幕
视频ID_zh.srt              中文字幕
视频ID_translations.json   翻译缓存
中文标题.mp4               最终视频
```

最终视频包含中文字幕和中文配音；如果标题翻译失败，则使用原标题命名。

## 声音克隆配音

基于 MiMo `mimo-v2.5-tts-voiceclone` 模型，可用原视频说话人的音色
来配音，而不是固定预置音色。启用方式：把 `tts` 配置改为 MiMo 引擎
并使用克隆模型：

```json
"tts": {
  "enabled": true,
  "engine": "mimo",
  "model": "mimo-v2.5-tts-voiceclone",
  "base_url": "https://api.xiaomimimo.com/v1",
  "api_key": "你的 API Key",
  "clone_ref_start_s": 0,
  "clone_ref_duration_s": 20
}
```

- 脚本会用 ffmpeg 从原视频截取一段单声道 wav 作为参考音频，转 base64
  后作为克隆音色，无需参考文本。
- `clone_ref_start_s` / `clone_ref_duration_s` 控制参考音频的起始位置和
  时长（默认从 0s 取 20s）；若片头是片头音乐/无人声，可调大
  `clone_ref_start_s` 跳过。
- 声音克隆需要原视频音频作参考，不能与 `--no-video` 同时使用。
- 参考音频变化时（如改 `clone_ref_duration_s`），TTS 缓存会自动失效
  重新生成。
- 未做人声分离；若原音背景音乐/噪声较大，克隆质量可能下降。

烧录字幕需要重新编码视频，是最耗时的步骤。若检测到支持 NVIDIA NVENC 的
ffmpeg 和显卡，会自动使用 GPU 硬件编码（`h264_nvenc`）替代 CPU 编码
（`libx264`），显著缩短烧录时间。

- 检测分两步：先查编码器列表，再空转编码 1 帧确认驱动/显卡真正可用。
- 检测失败或用 `--no-nvenc` 时，自动回退到 CPU `libx264`。
- 仅烧录字幕时涉及编码器选择；纯替换配音走 `copy`，不重新编码。
- 需要带 NVENC 的 ffmpeg 构建，可用 `ffmpeg -encoders | findstr nvenc`
  确认是否包含 `h264_nvenc`。
