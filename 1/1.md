# YouTube 视频中文字幕 + 中文配音工具 使用说明

一个自动化流水线：下载 YouTube 视频 → 提取词级字幕 → LLM 翻译成中文 → 生成 SRT 字幕 → 中文配音 → 一步合成带中文字幕和配音的最终视频。

## 功能特性

1. 自动检测视频默认语言（也可用 `--lang` 强制指定）
2. 下载视频 + JSON3 词级字幕（时间轴精确到词）
3. 按标点智能分句，保留精确的首尾时间戳
4. LLM 分批翻译（结构化 JSON 输出，按编号对齐，不会错位）
5. 自动拆分过长字幕、合并过短字幕，保证可读性
6. 中文配音：支持 edge-tts（免费）或 MiMo TTS（高质量），自动按时间槽调速避免压句
7. 字幕烧录 + 配音一步合成最终视频（只做一次视频转码）
8. 翻译结果逐批缓存：中断后重跑自动断点续传；重试后仍失败则中断程序
9. 最终视频以中文翻译标题命名

## 一、安装步骤

### 🪟 Windows

```bat
:: 1. 进入脚本所在目录
cd D:\workspace

:: 2. 创建并激活虚拟环境（推荐，可选）
python -m venv .venv
.venv\Scripts\activate
:: 激活成功后命令行开头会出现 (.venv)

:: 3. 安装 Python 依赖
pip install yt-dlp openai edge-tts numpy

:: 4. 安装 FFmpeg（两种方式任选其一）

:: 方式 A：用 winget（推荐，Win10 1809+ 自带）
winget install Gyan.FFmpeg

:: 方式 B：手动安装
:: 从 https://www.gyan.dev/ffmpeg/builds/ 下载 ffmpeg-release-essentials.zip
:: 解压后将 bin 目录添加到系统环境变量 PATH

:: 5. 关闭并重新打开命令行，验证安装
python --version
ffmpeg -version
ffprobe -version
yt-dlp --version
```

### 🍎 macOS


## 二、配置 API Key

**首次运行会自动生成配置模板** `config.json`（在脚本同目录），然后退出。用任意文本编辑器打开它：

```json
{
    "llm": {
        "provider": "mimo",
        "base_url": "https://token-plan-cn.xiaomimimo.com/v1",
        "api_key": "把你的API Key粘贴到这里",     ← 必填！
        "model": "mimo-v2.5-pro",
        "supports_system_role": false
    },
    "tts": {
        "enabled": true,
        "engine": "edge-tts",                     ← edge-tts 免费 / mimo 高质量
        "voice": "zh-CN-XiaoxiaoNeural",          ← 配音音色
        "rate": "+0%",
        "volume": "+0%",
        "pitch": "+0Hz",
        "mix_with_original": false                ← true 则保留原声混合
    },
    "subtitle": {
        "max_chars_per_line": 35,                 ← 单条字幕最大字符数
        "min_duration_ms": 800,                   ← 最短显示时长
        "max_duration_ms": 6000                   ← 超过则拆分
    }
}
```

**使用其他 OpenAI 兼容服务**（DeepSeek、通义千问等）只需改三项：

```json
{
  "llm": {
    "base_url": "https://api.deepseek.com/v1",
    "api_key": "sk-xxxx",
    "model": "deepseek-chat"
  }
}
```

> ⚠️ `supports_system_role`: 服务不支持 system 角色就保持 `false`（指令会拼入 user 消息）。

## 三、运行方式

### 基本用法

```bash
python 1.py "https://www.youtube.com/watch?v=DC471a9qrU4"
```

### 全部参数

| 参数           | 说明                                             |
| -------------- | ------------------------------------------------ |
| `url`          | YouTube 视频 URL（必填）                         |
| `-o, --output` | 根输出目录，默认 `./youtube_downloads`           |
| `--config`     | 指定配置文件路径（默认脚本同目录 `config.json`） |
| `--lang`       | 强制指定源语言代码（如 `en`, `ja`, `zh-CN`）     |
| `--no-video`   | 只生成字幕，不下载视频（也就不会有烧录和配音）   |
| `--no-burn`    | 跳过字幕烧录（有配音时仍会替换音轨）             |
| `--no-tts`     | 只烧录字幕，不做中文配音                         |

### 常用示例

```bash
# 完整流程（下载+字幕+烧录+配音）
python 1.py "https://www.youtube.com/watch?v=xxxxx"

# 只要中文字幕文件，不要视频和配音（最省钱省时）
python 1.py "https://youtu.be/xxxxx" --no-video

# 烧录字幕但不配音
python 1.py "https://youtu.be/xxxxx" --no-tts

# 日语视频强制指定语言
python 1.py "https://youtu.be/xxxxx" --lang ja

# 指定输出目录和配置文件
python 1.py "https://youtu.be/xxxxx" -o ./my_output --config ./deepseek.json
```

## 五、缓存与断点续传

- **翻译进度逐批保存**：每完成一批（40 句）立即写入缓存文件
- **失败即中断**：任何一批重试 3 次后仍失败，程序立即退出，不做占位降级
- **重跑自动续传**：再次运行同一视频时，已完成的句子直接命中缓存，只翻译缺失部分，不重复花钱
- **缓存失效条件**：换了模型、或视频字幕内容变化 → 缓存自动作废重翻
- ⚠️ TTS 音频片段没有缓存：改配音相关配置重跑会重新合成全部配音

## 六、常见问题排查

### 1. 无法访问 YouTube / 下载超时

需要代理。确保代理软件开启后，运行前设置环境变量：

```bat
:: Windows (cmd)，端口改成你代理软件的端口
set HTTPS_PROXY=http://127.0.0.1:7890
set HTTP_PROXY=http://127.0.0.1:7890
```

```bash
# macOS / Linux
export https_proxy=http://127.0.0.1:7890
export http_proxy=http://127.0.0.1:7890
```

### 2. `未找到 ffmpeg` 或音频拼接报错

确认 `ffmpeg` 和 `ffprobe` 都在 PATH 里（分别执行两个 `-version` 验证）。配音调速功能依赖 ffprobe。

### 3. `ModuleNotFoundError: numpy`

```bash
pip install numpy
```

### 4. 提示缺少 api_key

编辑 `config.json`，填入 `llm.api_key` 后重新运行。

### 5. 翻译中途失败后重跑

直接原样再运行一次即可——已完成的批次命中缓存，从断点继续，之前花的钱不浪费。

### 6. 找不到字幕 / 语言检测错误

该视频可能没有对应语言的自动字幕，用 `--lang en` 显式指定试试。

### 7. edge-tts 配音失败率变高

通常是并发被微软限流，稍等几分钟重跑即可（脚本自带限流与重试）。

## 七、成本小贴士

- 测试阶段优先用 `--no-video`（只要字幕），最快验证翻译质量
- 翻译缓存让反复调试零成本；但改配音配置会触发全部配音重新生成
- Fireship 类英语科技频道自动字幕质量高、标点齐全，适合作为标准测试素材
